# XenYarn

XenYarn optimizes high-performance, scalable resource allocation through real-time-processing and auto-scaling, serving as a centralized Hub and workload Scheduler.

XenYarn is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/XenYarn.git`
2. `cd XenYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure XenYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
